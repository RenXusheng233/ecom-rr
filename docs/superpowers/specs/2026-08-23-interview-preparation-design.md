# 全栈偏前端面试学习文档设计

## 目标

为拥有 5 年以上前端经验、正在向全栈方向发展的工程师制作一套可在 7 天内完成的中文面试学习资料。资料以当前 `ecom-rr` 项目为主线，帮助读者同时做到：

- 准确说明项目的架构、技术选型和业务链路；
- 回答 Next.js、认证授权、NestJS、数据库、Kafka 和 Redis 的高频追问；
- 识别当前实现的局限，并给出符合生产实践的演进方案；
- 形成适用于全栈偏前端岗位的项目介绍与面试回答。

## 读者定位与深度

- 岗位方向：全栈偏前端。
- 前端深度：掌握原理、选型和性能分析，重点覆盖 Next.js 16 App Router。
- 后端深度：能够解释完整业务链路和可靠性问题；NestJS 深入到模块设计、依赖注入、Guard、Pipe、Interceptor、Filter、测试与微服务模式。
- FastAPI：仅用于框架选型对照，不展开 Python 语言基础。
- 数据库与消息队列：从“会使用”提升到能回答事务、索引、建模、一致性和故障处理问题。

## 组织方案

采用“项目链路为主、面试题为辅”的方式。正文不会写成孤立的技术百科；每个模块均关联仓库中的实际实现，并区分“当前项目已实现”“生产环境建议”“扩展学习”。

输出目录为 `docs/interview-preparation/`，包含：

1. `README.md`：导航、使用方法和学习原则。
2. `00-一周学习路线与项目介绍.md`：7 天计划、项目架构、业务链路及项目介绍模板。
3. `01-Next.js全栈前端与性能优化.md`：App Router、Server/Client Components、渲染策略、缓存、revalidate、SEO、流式渲染、Zustand、Tailwind CSS、shadcn/ui 和性能排查。
4. `02-Clerk认证授权与自研方案.md`：认证与授权、Cookie/JWT/Session、Clerk 与自研对比、RBAC、安全风险及 NestJS 自研方案。
5. `03-Node.js微服务框架与NestJS.md`：Express、Fastify、Hono、NestJS 和 FastAPI 对比；NestJS 核心机制、选型和服务拆分。
6. `04-数据库选型建模事务与ORM.md`：PostgreSQL/MongoDB/Redis 边界、Prisma/Mongoose/TypeORM/Drizzle 对比、表结构、索引、事务、隔离级别与迁移。
7. `05-Kafka事件驱动与可靠性.md`：Topic、Partition、Consumer Group、Offset、交付语义、幂等、重试、死信、顺序、Outbox 和项目事件链。
8. `06-Redis缓存与分布式能力.md`：数据结构、缓存策略、穿透/击穿/雪崩、分布式锁、限流、Session、消息能力及项目接入点。
9. `07-系统设计改进与项目追问.md`：支付下单一致性、服务边界、可观测性、容错、安全、部署与渐进式演进。
10. `08-高频面试题与参考答案.md`：分层问题、回答要点和项目化表达。

## 统一章节模板

每份模块文档按需包含：

1. 本章学习目标与建议耗时；
2. 项目中的代码映射和真实调用链；
3. 核心概念与工作原理；
4. 技术方案对比与选型依据；
5. 当前实现的优点、局限及生产化改进；
6. 面试回答模板与常见追问；
7. 自测清单；
8. 精选官方或一手资料链接。

## 内容约束

- 以仓库代码为事实来源，不虚构性能指标、并发量、故障恢复能力或尚未实现的功能。
- 清楚标注当前实现与建议方案，例如项目当前尚未实现 Kafka 幂等消费、事务 Outbox、Redis 缓存时，不将其描述为已有成果。
- 优先解释“为什么”和“如何权衡”，避免大段 API 罗列。
- 示例以 TypeScript、NestJS 和当前电商业务为主，代码仅保留帮助理解面试问题的最小片段。
- 外部资料优先引用 Next.js、Clerk、NestJS、PostgreSQL、MongoDB、Prisma、Kafka 和 Redis 官方文档。
- 总体阅读与练习时间控制在约 18 至 24 小时，可在 7 天内完成。

## 验收标准

- 所有计划文件均存在，目录导航和内部链接有效。
- 关键技术结论能由项目代码或官方资料支持。
- Next.js 章节覆盖 SEO、缓存、`revalidate` 和渲染优化。
- Clerk 章节给出 SaaS 与自研认证的明确对比及 NestJS 实现路线。
- 框架章节以 NestJS 为重点，同时解释本项目采用多框架的收益和成本。
- 数据库章节覆盖建模、索引、事务与 ORM/ODM 选型。
- Kafka 章节覆盖可靠消费、幂等、重试、死信和 Outbox。
- Redis 章节与电商项目给出具体接入场景。
- 每天都有学习任务、输出物和自测题，最终能够完成一次项目模拟面试。
